# ICAUR × CBH

Apresentação comercial da plataforma ICAUR dentro do hipismo brasileiro.

## Como publicar no GitHub Pages
1. Suba `index.html` e a pasta `assets/` na raiz do repositório, mantendo a estrutura.
2. Em **Settings › Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O link fica disponível em alguns minutos em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

A página também abre localmente: basta dar dois cliques em `index.html` com a pasta `assets/` ao lado.
